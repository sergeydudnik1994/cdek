Вопросы ИП о договоре СДЭК для маркетплейсов

В чем выгода договора СДЭК по сетке УСН для ИП на маркетплейсах? ▾

При регистрации договора по льготной сетке УСН не начисляется 22% НДС. Для ИП на УСН «Доходы» и Патенте это снижает логистическую себестоимость доставки каждого отправления по схемам FBS и DBS.

Как передаются трек-номера СДЭК в кабинет селлера Ozon, WB и Яндекс Маркета? ▾

Через официальный API v2 или готовые модули трек-номера и статусы доставки (в пути, прибыл в ПВЗ, вручен) автоматически транслируются в личный кабинет продавца, предотвращая штрафы площадок за нарушение сроков.

Можно ли сдавать заказы маркетплейсов в любой ПВЗ СДЭК? ▾

Да. ИП с заключенным договором может сдавать упакованные посылки без очередей в любом из 5 000+ пунктов выдачи СДЭК по всей России либо оформить забор курьером со своего склада.
