Вопросы юридических лиц о договоре СДЭК

Предоставляются ли закрывающие документы с выделенным НДС 22%? ▾

Да. Для организаций на общей системе налогообложения (ОСНО) оформляется договор с выделением НДС 22%. Ежемесячные УПД и акты сверки передаются через системы ЭДО (Диадок, СБИС) для беспрепятственного налогового вычета.

Как организованы поставки FBO на распределительные склады маркетплейсов? ▾

СДЭК принимает партии коробок или сформированные европаллеты, маркирует грузовые места в соответствии с регламентами Wildberries, Ozon и Яндекс Маркета и доставляет груз на склад маркетплейса точно в забронированный тайм-слот.

Как работает постоплатная система расчетов для ООО? ▾

Организация отправляет грузы и заказы в течение месяца без внесения предоплаты. По итогам расчетного периода формируется сводный счет на оплату логистических услуг с согласованной отсрочкой платежа.

Как быстро подключается API для выгрузки заказов из 1С и МойСклад? ▾

Боевые ключи API v2 (Account и Secure Password) генерируются сразу после подписания договора. Готовые модули для 1С:Предприятие и МойСклад настраиваются за 15-30 минут.
