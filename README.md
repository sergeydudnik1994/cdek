# CDEK Marketplace — B2B Лендинг для селлеров

Официальный веб-сайт для подключения продавцов маркетплейсов (Wildberries, Ozon, Яндекс Маркет, Авито) к логистике и сервисам СДЭК.

Твоя рабочая (боевая) папка на сервере — это /var/www/cdek-html. Именно этот путь должен быть прописан в директиве root в конфигурации Nginx, чтобы сайт отображался корректно! my.selectel.ru/vds
