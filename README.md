# CDEK Marketplace — B2B Лендинг для селлеров

Официальный веб-сайт для подключения продавцов маркетплейсов (Wildberries, Ozon, Яндекс Маркет, Авито) к логистике и сервисам СДЭК.

## 🚀 Технологический стек

* **Фреймворк:** Astro
* **Стилизация:** Tailwind CSS
* **Контент:** Astro Content Collections (Markdown)
* **Деплой & Хостинг:** Vercel

## 📁 Структура проекта

* `src/pages/` — страницы сайта (главная и список статей `/blog`)
* `src/content/blog/` — файлы статей блога в формате `.md`
* `src/components/` — UI-компоненты (шапка, подвал, форма заявки, FAQ)

## ✍️ Управление блогом

Для добавления новой статьи создайте файл `.md` в папке `src/content/blog/` со следующей шапкой:

```yaml
---
title: "Заголовок статьи"
description: "Краткий анонс статьи"
pubDate: "2026-08-02"
---
